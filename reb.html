1. Introduction to HTML

  • HTML = HyperText Markup Language.
  • Tags (markup) tell a web browser how content should be displayed.
  • Tags usually come in pairs with content sandwiched between them: an opening tag and a closing tag (the closing tag has a forward slash).
  • Examples: header tags (titles), <p> (paragraphs), <a> (hyperlinks).
  • House analogy: HTML is the foundation / skeleton (structure). CSS (Cascading Style Sheets) is the decoration, design and colors (style).
  • You need a modern web browser (Chrome, Firefox, Edge, Safari) and a text editor (such as VS Code, which is free).
  • Why learn it: almost every business has an online presence, so knowing how to manage a website is a useful skill.

2. Setup: VS Code, Project Folder, Live Server

  1. Download VS Code from code.visualstudio.com (pick your operating system) and install it.
  2. In VS Code, choose Open Folder and create a folder for your website (example: website on the desktop).
  3. Create a new file named index.html. The homepage should be named index because most servers return the index file as the homepage.
  4. Install the Live Server extension (Extensions tab, search "live server", install). It automatically refreshes the browser when you save your HTML file.
  5. To view the page: right-click the HTML file, then Open with Live Server.

3. HTML Basics

Basic page skeleton

<!DOCTYPE html>
<html>
  <head>
    <title>My first website</title>
  </head>
  <body>
    <h1>This is an H1 heading</h1>
    <p>Some text goes here.</p>
  </body>
</html>
PartMeaning
<!DOCTYPE html>Declaration that the document is an HTML5 document (most recent version).
<html>Root element of the page.
<head>Information about the page (such as the title). Not visible content.
<title>Text shown in the browser tab.
<body>The visible content of the page.

Headings, paragraphs and other basics

  • Headings: <h1> (largest) down to <h6> (smallest). Used for titles or other large text.
  • Paragraph: <p>. Paragraphs are separated by a line break, and they ignore extra spaces and new lines in your code.
  • Line break: <br> (self-closing, no closing tag needed).
  • Horizontal rule: <hr> (self-closing). Draws a horizontal line, nice after a title.
  • Preformatted text: <pre> keeps the spaces and line breaks you type (useful for song lyrics).
  • Comments: <!-- this is a comment -->. Not displayed; used as notes for yourself or other developers.
  • Typing lorem then Tab in VS Code generates sample Latin-like text.
  • Typing ! then Tab in VS Code generates a basic HTML template.

Remember: Self-closing tags (br, hr, img, input, link) have no content, so they have no closing tag.

4. Hyperlinks

A hyperlink is a digital reference to data that a user can follow by clicking or tapping. Use the anchor tag <a> with the href attribute.

<a href="https://www.google.com" target="_blank" title="Goes to Google">Click me</a>
  • Attribute = usually a name/value pair that modifies the behavior of an element.
  • a = anchor. href = hypertext reference (what you are linking to; a web page or file).
  • target="_blank" opens the link in a new tab or window (optional).
  • title shows extra information as a tooltip on hover (optional).
  • Absolute URL: full address, e.g. https://www.google.com.
  • Relative URL: a file path relative to the current file. Files in the same folder only need the file name, e.g. href="lyrics.html".
  • Email link: <a href="mailto:test@fake.com">Email me</a> starts the process of sending an email.

5. Images

<img src="dog.png" height="200" alt="This is a picture of a dog">
  • <img> is a self-closing tag.
  • src = source: the file name including the extension (be sure the extension is correct, e.g. png vs jpg).
  • height / width set the dimensions. If you set only one, the other adjusts automatically. Setting both can compress/distort the image.
  • alt = alternative text. It displays if the image fails to load, and screen readers read it aloud for visually impaired users. Always write a brief description.
  • Image as a hyperlink: surround the img with <a href="...">...</a>.
  • GIFs are included the same way as other images.
  • Images folder: if images are kept in a folder, include the folder in the path: src="images/dog.png".

6. Audio

<audio controls>
  <source src="music/song.mp3" type="audio/mp3">
  <source src="music/song.wav" type="audio/wav">
</audio>
  • Use a pair of <audio> tags with <source> element(s) inside. src is the audio file name (with extension).
  • controls: shows play, pause, mute, fast forward, rewind and playback speed. Without it, nothing appears.
  • autoplay: plays automatically (not recommended, people find it annoying). If used, add muted.
  • muted: starts muted.
  • loop: repeats the audio.
  • Fallbacks: add more source elements (e.g. a WAV backup for an MP3). The type attribute tells the browser the file type (audio/mp3, audio/wav).
  • Tip: put audio files in a music folder and use src="music/filename". Add a <p> before each player to label the song.

7. Video

<video width="500" controls autoplay muted loop>
  <source src="zelda.mp4" type="video/mp4">
  <source src="zelda.webm" type="video/webm">
</video>
  • Supported formats: mp4, webm, ogg.
  • Use a pair of <video> tags. Set width or height (the other adjusts automatically).
  • controls lets the user play the video. autoplay plays on page load (always add muted with it). loop repeats it.
  • Use <source> elements with type (e.g. video/mp4) to provide backup formats. The browser uses the first one it supports.
  • A video can be turned into a hyperlink by surrounding it with <a>. Use target="_blank" to open in a new tab.

8. Favicons

A favicon is the small icon shown in the browser tab.

<head>
  <link rel="icon" type="image/jpg" href="images/favicon.jpg">
</head>
  • Recommended image size: at least 96 x 96 pixels.
  • Most modern browsers accept ico, png, gif, jpeg, svg.
  • <link> is self-closing and specifies the relationship between this document and an external source.
  • rel="icon" (relationship = icon), type="image/<file type>", href = relative file location.
  • If the image is in a folder, include the folder in the path (images/favicon.jpg).
  • The link tag goes inside the head.

9. Text Formatting

Text formatting gives text special emphasis. Surround the text with the proper pair of tags. Always close your tags, or the effect will cascade through the rest of the document.

TagEffect
<b>Bold
<i>Italic
<u>Underline
<del>Deleted text
<big>Big text (larger than surrounding text)
<small>Small text
<sub>Subscript (smaller, just below the line), e.g. H2O
<sup>Superscript (smaller, just above the line), e.g. x2
<tt>Monospaced text
<mark>Highlighted text (like a highlighter; color can be changed with CSS)
<mark style="background-color:lightgreen;">highlighted</mark>

10. Span & Div

TagTypeBehavior
<span>Inline containerGroups elements for styling; only takes up as much space as its content.
<div>Block-level containerGroups elements for styling (div = division); takes up the entire width of the document.
<h1><span style="background-color:tomato;">This is a span title</span></h1>
<h1><div style="background-color:cyan;">This is a div title</div></h1>
  • Both are used to group HTML so you can apply (inline) CSS styling to whatever is between the tags.
  • They will be used much more once you reach CSS.

11. Lists

Three types of lists:

List typeTagsNotes
Unordered list<ul> with <li> itemsBulleted; order doesn't matter (e.g. grocery list).
Ordered list<ol> with <li> itemsNumbered; order matters (e.g. to-do list).
Description list<dl> with <dt> (term) and <dd> (definition)Key/value pairs: a term and its definition.
<h4>Groceries</h4>
<ul>
  <li>Milk</li>
  <li>Eggs</li>
  <li>Coffee supplies
    <ul>
      <li>Coffee beans</li>
      <li>Creamer</li>
    </ul>
  </li>
</ul>

<dl>
  <dt>Dragon</dt>
  <dd>A mythical monster resembling a giant reptile.</dd>
</dl>
  • li = list item. dt = description term. dd = description definition.
  • Nested lists: place a new ul inside an li (nested bullets appear hollow).
  • Lists can be styled with CSS (e.g. background color, border).

12. Tables

<table border="1">
  <tr>
    <th>Sunday</th>
    <th>Monday</th>
  </tr>
  <tr align="center">
    <td>Closed</td>
    <td>9 to 5</td>
  </tr>
</table>
Tag / AttributeMeaning
<table>The table.
<tr>Table row.
<th>Table header cell (one per column in the header row).
<td>Table data cell.
borderOn table. 0 = no border; higher number = thicker border.
alignOn tr. Values such as center to align the data.
widthOn th. Makes columns a uniform size.
style="background-color: ..."Inline CSS to color the table or individual rows.
  • The first row is usually the table headers; add one header per column.
  • Each column's data must line up under its header, so use the same number of cells in each row.
  • Add more rows with more tr tags.

13. Buttons

<button style="font-size:25px; background-color:gray; color:lightblue; border-radius:25px;">Click me</button>
  • Use a pair of <button> tags with text between them.
  • Style with inline CSS (separate properties with semicolons): font-size, background-color, color, border-radius (rounded corners).
  • Button as a link: wrap the button in <a href="page2.html">...</a> to go to another page or site.
  • Button that runs JavaScript (just for awareness): use the onclick attribute with a function name. The function is defined inside <script> tags.
<script>
  function doSomething() {
    document.getElementById("greeting").innerHTML = "Goodbye";
  }
</script>
<button onclick="doSomething()">Click me</button>
<p id="greeting">Hello</p>
  • With many CSS properties, using a stylesheet is recommended instead of inline CSS (covered later).

14. Forms

The form element

<form action="action_page.php" method="post" enctype="multipart/form-data">
  ...
</form>
  • action: the location (file) the form data is sent to. Form submission is handled by a backend language such as PHP.
  • method: post for sensitive/confidential data (username, password); get for non-sensitive data.
  • enctype="multipart/form-data": use when sending large data such as an image. Data is split into multiple parts and reassembled when received.

Labels

  • Add a <label> so users know what to enter.
  • The label's for attribute must match the input's id. This helps screen readers, and clicking the label moves the cursor to the input.
<label for="username">Username:</label>
<input type="text" id="username" required minlength="6" maxlength="15" placeholder="SpongeBob">

Form elements and input types

ElementCodeNotes
Text box<input type="text">Default type is text.
Password<input type="password">Characters are hidden.
Email<input type="email">Browser checks for a valid email format (needs an @).
Telephone<input type="tel">Use pattern="[0-9]{3}-[0-9]{3}-[0-9]{4}" to force a format.
Date<input type="date">Shows an interactive calendar.
Number<input type="number" min="0" max="99" value="1">Use min, max and a default value.
Radio buttons<input type="radio" name="title" value="Mr">Only one can be selected per group. Buttons in the same group must share the same name. Each needs its own value.
Drop-down menu<select> with <option value="...">Options go inside the select tags.
Checkbox<input type="checkbox">For yes/no choices (e.g. subscribe).
Text area<textarea rows="3" cols="25"></textarea>Multi-line text; set size with rows and columns.
File upload<input type="file" accept="image/png, image/jpeg">accept limits file types (comma-separated).
Submit button<input type="submit">Sends the form data.
Reset button<input type="reset">Clears the form data.

Useful input attributes

  • required: the form cannot be submitted until the field is filled in.
  • minlength / maxlength: minimum / maximum number of characters.
  • placeholder: faded hint showing the expected format; disappears when you type.
  • pattern: restricts input to a format (e.g. phone numbers).
  • min / max / value: for number inputs (smallest, largest, default).
  • id: unique identifier; matches the label's for.
  • name: groups radio buttons together.
  • accept: allowed file types for file inputs.

15. Headers & Footers

<header> and <footer> are semantic tags: they describe their meaning to both the web browser and the developer. They help organize content and make it easier to apply CSS to everything inside them.

<body>
  <header>
    <h1>Welcome to My Page</h1>
    <a href="">Home</a> <a href="">About us</a>
    <hr>
  </header>

  <main>
    <h4>Check out these cool moves:</h4>
    <img src="profile.jpg" alt="profile pic">
    <p>Main content here.</p>
  </main>

  <footer>
    <hr>
    Author: Your Name <br>
    &copy; All rights reserved <br>
    <small><a href="mailto:bro@fake.com">bro@fake.com</a></small>
  </footer>
</body>
  • Header: introductory content at the top: title, subtitle, logo, navigation bar (hyperlinks).
  • Footer: concluding content at the bottom: author, copyright, contact info (phone, email).
  • Main: wraps the main content of the page (helps organization).
  • Copyright symbol in HTML: &copy; (shows ©).
  • Inline CSS example: <header style="background-color: mediumpurple;">.
